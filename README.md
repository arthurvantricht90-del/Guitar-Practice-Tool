# Frettr — Guitar Practice

**Frettr** is a browser-based practice tool that helps guitarists learn the fretboard through short, interactive exercises. It combines recall training (identify, then reveal), timed drills and play-along backing, all configurable to your own level.

**Live demo:** https://frettr.netlify.app/

## Why I built it
As a guitarist, I was looking for a tool that could help me practice certain aspects of guitar playing, but I could not find a tool that did exactly that what I was looking for. So I built it myself.

## Features

| Module | What it trains |
|---|---|
| **Chord Trainer** | Recognise chord shapes across the neck, then reveal the names to check yourself. Choose chord types (major, minor, major 7th, minor 7th), include G shapes, and set how many chords appear per round. |
| **Scale Trainer** | See major, minor and pentatonic patterns mapped across the fretboard for any root. Optional note names, with the root note highlighted. |
| **Triad Trainer** | Identify triads and their inversions (root position, 1st, 2nd) on different string sets (E-B-G, B-G-D, G-D-A, D-A-E). |
| **Fretboard Trainer** | Name the marked note before a configurable timer runs out. The answer shows briefly, then a new note appears. |
| **Key Jam** | Chords from one key arrive in tempo so you can play along. Choose key, mode, tempo (BPM), bars per chord (1, 2 or 4), a metronome click and optionally the diminished (vii°) chord. |

### Usability

- Light and dark theme
- Keyboard shortcuts (space / enter to reveal or advance)
- Responsive layout with a landscape hint and a larger view on phones
- Per-exercise options panel so every drill can be tuned to your level
